# End to End Devops Project for three tier application
----

## Download AWS CLI or run below commands in cloudshell

Download AWS CLi using link : https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html

## Create new IAM user for whole project.

 aws iam create-user --user-name bloodbank

## Create secret keys for above created user

aws iam create-user --user-name bloodbank

## Configure aws in visual studio code
